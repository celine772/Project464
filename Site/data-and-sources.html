Data and Sources

This map was created using three data sets, all sources from the City of Montréal's open data portal. Below are the details for each data set.

Free Wi-Fi dataset

Publisher: Strategic Planning, Performance and Innovation Department

Link: https://donnees.montreal.ca/dataset/couverture-du-reseau-wifi-mtlwifi#additional-info

How this data was used: The original dataset included some wifi spots that were inactive, so they were removed from the data set.

Public Drinking Fountains dataset

Publisher:Borough Consultation and Citizen Experience Service / Boroughs

Link: https://donnees.montreal.ca/dataset/fontaines-a-boire-eau-exterieures

How this data set was used: The original dataset included some fountains that had restrained access, so they were removed from the data set.

Attractions dataset

Urban Planning and Mobility Department

Link: https://donnees.montreal.ca/dataset/lieux-d-interet

How this data was used: This dataset was orinally much larger and included sports and other facilities that were not relevant to the map. They were removed from the data set, and only the tourist attractions were kept.
